# Masu Hisab (मासु हिसाब)

Village meat cutting accounts for goat (kg), pig (dharni) and buffalo (bhag):
orders, weighing and comparing, payments with dates, one-tap SMS/WhatsApp reminders,
weight guess (photo measure with a Rs 1 coin, person or stick; tape formula) and a
private "My sales" record with photos.

Open the site on a phone and choose **Add to Home screen** to install it like an app.
It works without internet. All records stay on that phone; use **Settings → Save a backup file**
now and then.

## Android app (APK)

Direct download: https://github.com/Saroj010/masu-hisab/releases/latest/download/masu-hisab.apk

GitHub builds the APK automatically on every change (see `.github/workflows/android.yml`).
The build needs the repository secret `KS_PASS` (the signing password) so that every new version
installs over the old one and keeps the records on the phone.
